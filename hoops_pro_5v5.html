HOOPS PRO 5v5 — 總教練戰術與花式技巧指南

🌀 花式過人技巧 (Spin / Euro-Step / Crossover)

按下 X / C 鍵（喊炫技！） 或由高能力球員自主觸發：持球者會根據場上位置施展 360°陀螺轉身過人、迷蹤歐洲步上籃 或 胯下變向晃倒 (Ankle-Breaker)，帶有彩色動態殘影！

🏹 後撤步三分與高拋投 (Step-Back & Floater)

按下 Z / V 鍵（喊後撤步！）：若持球者在中遠距離，會立即向後大跨步施展 哈登式後撤步跳投（大幅降低防守干擾度）；若在禁區附近，則會施展超高弧度 彩虹高拋投 (Floater) 閃避中鋒火鍋！

🔥 連進手感發燙 (On-Fire) 與士氣

當球員連續命中 2 球以上，腳下會燃起 🔥發燙雙層光環，大幅提升綠燈區間與切入速度！適時按下 空白鍵 / Q 鍵（喊加油） 更能讓全隊體力與士氣瞬間沸騰。

🔄 板凳換人與體力輪換 [按 T]

劇烈花式動作與衝刺會消耗體力。您可以按 T 鍵 打開換人視窗派遣板凳奇兵上場，或交給 AI 自動輪換休息。

總教練鍵盤快捷鍵一覽：
  • • [空白鍵 / Q] 喊加油： 全隊恢復體力 + 士氣熱血加成
  • • [J / S] 喊投籃： 命令持球球員立刻果斷跳投或強起終結
  • • [D] 喊切入： 命令持球球員強行加速衝擊籃框飛身爆扣
  • • [X / C] 喊炫技： 施展 360°陀螺轉身、迷蹤歐洲步或變向晃倒對手
  • • [Z / V] 喊後撤步： 施展後撤步三分跳投 (Step-Back) 或禁區高拋投
  • • [K / P] 喊傳球： 施展不看人妙傳或擊地傳球給最佳空檔隊友
  • • [U / A] 喊空接/擋拆： 呼叫中鋒掩護順下或直接高吊空中接力爆扣
  • • [L / F] 喊防守： 命令全隊進入壓迫防守，積極抄截與追魂鍋封阻
